# Source 01 — W3C WCAG 2.2

- URL: https://www.w3.org/TR/wcag/
- Type: Primary standard
- Retrieved: 2026-10-17
- Credibility: High
- Recency: Current WCAG 2.2 recommendation
- Bias: Standards-oriented; not a visual-design guide

## Relevant evidence

> “The size of the target for pointer inputs is at least 24 by 24 CSS pixels.”

> “All functionality that uses a dragging movement for operation can be achieved by a single pointer without dragging.”

## Design implication

Keep filter tabs, CTAs, and card actions comfortably tappable, and ensure swipe discovery has equivalent button actions.
