# F2 — Own the booking category

## Thesis

PacaRent should feel like its own booking marketplace, not a dating-app clone.

## Evidence

- Internal UX research names “Tertarik → Booking” as the core adaptation.
- Booking requires date, duration, location, payment, and completion status; these are planning concepts.
- A calendar/check vocabulary is more semantically aligned than heart/match vocabulary.

## Implementation consequence

Use teal as the trust/action color, calendar/check icons for booking, and plain Indonesian labels that describe the next step.
