# F1 — Empty state is a product surface, not a placeholder

## Thesis

When inventory is absent, the screen still needs to communicate status, teach the next step, and offer a direct path into the product.

## Evidence

- W3C supports clear, operable controls and equivalent non-drag actions.
- NN/G recommends communicating status, offering learning cues, and providing direct pathways from empty states.
- PacaRent’s own launch state is a real first-use journey, not an edge case.

## Implementation consequence

Use a composed empty state with a short explanation, three-step booking model, and two action paths: become a partner or switch to card mode.
